# 🎬 Amazon Prime Video Analytics Dashboard

### 📊 An Interactive Power BI Data Analytics Project

An interactive, multi-page Power BI dashboard designed to explore content distribution, viewership patterns, ratings, and watch-time trends using a synthetic Amazon Prime Video dataset.

---

## 📌 Project Overview

This project demonstrates how data analytics and visualization can transform raw content data into meaningful insights.

The dashboard provides an interactive experience through three pages: Home, Movies, and TV Shows. Users can explore content performance through KPIs, charts, slicers, and cross-filtering.

**Note:** This project uses synthetic data for educational and portfolio purposes. It does not represent actual Amazon Prime Video internal data or business performance.

---

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Explore viewership and watch-time patterns.
- Identify popular genres and content categories.
- Examine IMDb ratings and rating counts.
- Compare content performance across countries and regions.
- Explore TV show season distribution.
- Build an interactive and visually consistent Power BI dashboard.

## 📊 Dashboard Pages

### 🏠 1. Home Dashboard

Provides an overall view of the content dataset.

Key analysis:
- Overall content KPIs
- Movie vs. TV Show distribution
- Viewership trends
- Genre performance
- Content distribution across regions

### 🎬 2. Movie Dashboard

Focuses on movie-related analysis.

Key analysis:
- Top-performing movies
- IMDb ratings
- Movie duration distribution
- Genre-wise watch time
- Movie performance across release years

### 📺 3. TV Show Dashboard

Focuses on TV show distribution and performance.

Key analysis:
- Show distribution by season count
- Viewership by country
- Genre and regional analysis
- Popular TV shows
- Watch-time patterns

*The dashboard visuals and available metrics determine the exact analyses supported on each page.*

---

## 💡 Key Business Questions

This dashboard helps explore questions such as:

1. How are Movies and TV Shows distributed in the dataset?
2. Which genres have the highest total views?
3. Which movies have the highest IMDb ratings?
4. How does watch time vary across release years?
5. Which countries have the highest recorded viewership?
6. How are TV shows distributed across season categories?
7. Which languages and content categories show higher watch time?
