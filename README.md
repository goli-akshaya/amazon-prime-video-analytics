# 🎬 Amazon Prime Video Analytics Dashboard

### Interactive Data Analytics Project | Microsoft Power BI

An interactive, multi-page Power BI dashboard designed to analyze content distribution, viewership, ratings, and watch-time patterns using a synthetic Amazon Prime Video dataset.

---

## 📌 Project Overview

This project transforms raw content data into interactive visual reports using Microsoft Power BI. It explores content performance, identifies patterns across genres and regions, and translates analytical findings into actionable business recommendations.

The dashboard consists of three dedicated pages:

- 🏠 **Home Dashboard** — Overall content distribution and performance.
- 🎬 **Movie Dashboard** — Movie ratings, duration, and viewing patterns.
- 📺 **TV Show Dashboard** — Season distribution, regional viewership, and show performance.

---

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Identify genres with higher recorded viewership.
- Evaluate movie ratings and rating counts.
- Explore watch-time patterns across content categories.
- Compare content metrics across countries and regions.
- Analyze movie durations and TV show season distribution.
- Develop business recommendations based on dashboard findings.
- Build an interactive dashboard using Power Query, DAX, and Power BI.
